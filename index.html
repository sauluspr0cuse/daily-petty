Daily Petty Help Centre

User Guide

Learn the app at your own pace, or start a guided tour that points to the real controls.

1. Create and organise books

From My Books, choose Create New Book. Create a separate book for each purpose, such as household expenses or a shop. Each book keeps its own entries and settings.

2. Only Expenses

Choose the date, press Add Expense, then enter particulars, category and amount. Review the daily total. If using a budget, set a realistic limit and review suggestions when spending exceeds it.

3. Income & Expenses

Record money received as receipts and money paid as payments. Check the opening and closing cash balances and carry-forward. A transfer or loan repayment should not automatically be treated as ordinary income.

4. Sales

Set up products in Product Catalogue before recording product sales. Check quantity, rate, amount and payment status. Sales revenue is not the same as profit; product costs must also be considered.

5. Reports & suggestions

Select the period carefully before reviewing daily, monthly, yearly or book-year figures. Spending Insights offers basic rule-based observations from recorded transactions, not professional financial advice.

6. Back up your data

Export a JSON backup regularly and store a copy somewhere safe. Restore can replace the records in the current browser, so back up first and read the confirmation carefully. Browser storage does not sync automatically across devices.
